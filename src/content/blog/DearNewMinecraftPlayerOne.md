### 2.Java

#### 2.1.最低Java版本要求

- 从1.12（17w13a）开始，运行Minecraft的最低要求是Java 8。

- 从1.17（21w19a）开始，运行Minecraft的最低要求是Java 16。

- 从1.18（1.18-pre2）开始，运行Minecraft的最低要求是Java 17。

- 从1.20.5（24w14a）开始，运行Minecraft的最低要求是Java 21，且操作系统要求为64位。

### 3.关于模组加载器

关于模组加载器，你可能需要知道：

- Forge：一个支持版本极多的主流 API ，但是随着人员的变动，绝大多数开放人员都迁移到了  NeoForge 。

​	[[Forge\]Minecraft Forge - MC百科](https://www.mcmod.cn/class/30.html)

- Fabric ：冉冉升起的新星。我对它们的刻板印象是，Fabric 擅长相对轻度的模组，与之相对的是 Forge 的重工业模组们。

​	[FabricMC - 开发团队 - MC百科](https://www.mcmod.cn/author/22594.html)

- NeoForge：NeoForge 是 Minecraft Forge的分支。几乎所有 Minecraft Forge 团队成员都加入了新的团队。

​	[NeoForge - MC百科](https://www.mcmod.cn/class/11433.html) 

总之三者几乎不能混用，虽然有额外情况，比如使用 `信雅互联` 等，但是对于初入 Minecraft Java 的新手们，还是看清你下载的模组基于什么模组加载器为好。

### 5.安装模组

PCL2 支持内置的下载，可以很方便的下载模组，当然有些未收录的或者未同步的模组你需要在 mc百科 上面寻找下载方式了，毕竟有些模组或者整合包作者喜欢发网盘……

具体的操作方法很简单，自己摸索就会了：在 启动 里面找到你想要玩的版本，之后前往 下载 来下载模组：

<img src="https://t.tutu.to/img/mrKan" alt="在 PCL2 下载模组" class="responsive-image"  />

当然，需要和你选择的 Minecraft 版本号和模组加载器（Forge/Fabric/NeoForge/…）对得上的模组。

### 6.安装整合包

假如你想安装整合包，一般来说有更简单的办法，你只需要把压缩包往 PCL2 或者 HMCL 一拖动，是的，鼠标长按压缩包，拖进启动器，一般来说即可自动安装。

如果拖入启动器没有反应，那大概是懒狗包，解压即可。



### 7.关于资源包

一般来说，资源包路径位于

`你的 Minecraft 安装路径\.minecraft\versions\你的包名\resourcepacks`

你也可以直接在游戏内

`选项-资源包 `

拖入资源包压缩包即可，不需要解压。
